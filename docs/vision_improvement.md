# 现有图片的孔位与位姿改进

日期：2026-11-04。此次仅改进离线复核建议和图片评价，不启动相机或机器人，不重训模型，也不修改原始标注、训练参数或控制门槛。

## 使用方法

重启九孔复核服务后，新的候选补全自动生效：

```powershell
conda activate ev-charging
python -m ev_charging.review.review_keypoints
```

对已有图库图片比较三维模型：

```powershell
python -m ev_charging.vision.evaluation.evaluate_library_keypoints --annotations dataset/vision/keypoint_annotations.json --output-dir artifacts/keypoint_pose_comparison --geometry config/geometry_nominal.json --geometry config/geometry_cad_socket_openings.json
```

每次使用新的输出目录。只有保存了与图片绑定、哈希一致且分辨率匹配的相机参数时才计算位姿；不会用其他设备或近似内参补齐。所有位姿结果均不授权机器人运动。

## 孔位结果与证据边界

使用冻结的同一份标注、同一权重和 5 原像素诊断邻域。13 张已确认图片共有 81 个可见参考点，其中 58 个为人工编辑，23 个为原样自动建议；后者不是独立精度证据。

| --- | ---: | ---: |
| 同名候选落在参考点 5 px 内 | 29/81 | 33/81 |
| 人工编辑参考点中匹配 | 6/58 | 10/58 |
| 原有匹配丢失 | — | 0 |
| 可见参考点上的输出偏差超过 5 px | 0 | 0 |

| 两张具备完整九孔参考的图中，完整输出九孔 | 0/2 | 1/2 |

所有原有预测坐标保持不变，新增四个匹配均来自人工编辑参考点。一张图由 6 个候选补全为 9 个。上述是同批开发回归，图片已经用于诊断和方案比较，不是独立测试集。

实现只在已有主孔、PE、方向与结构证据一致时补全缺失的小孔；补点必须来自已测量的内孔边界，保持尺寸约束、拓扑和唯一性。辅助暗区轮廓需在多个强度水平稳定出现，输出取真实拟合轮廓的中心，不取模板投影或平均坐标。已有候选不会被替换。

直接把更多阈值候选加入全局匹配的试验虽然恢复了更多点，但也新增了多处超过 5 px 的中心偏差，未采用该方案。控制/实时定位前端及原匹配门槛保持原样。
