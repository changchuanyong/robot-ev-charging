## 已完成验证

- 项目 Python 3.12 虚拟环境已安装 `requirements-control.txt` 中的依赖；OpenCV 4.13 支持本实现所需的 Tsai 手眼接口。
- 120 项自动测试全部通过，覆盖坐标与力矩参考点、风险解析解、导纳、状态机、独立停止反馈、视觉与控制契约、数据划分及实际 GRU 训练/加载。日志：`artifacts/final_tests.log`。
- A—F 六组方法均在明确标为合成的场景中完成；这些不是实体充电接口成功率。
- 七种异常按预期终止：卡滞→`progress_stall`，过载→`hard_wrench_limit`，过期→`feedback_stale`，断连→`feedback_invalid`，无接触→`contact_not_found`，无效视觉→`task_timeout`，域外载荷→`risk_domain_invalid`。
- 上述13条完整记录回放的决策差异为0，报告为 `artifacts/control_validation_v2/report.json`。
- 合成九类力觉数据共有45条轨迹，训练/验证/测试分别为27/9/9条；完成10轮训练与独立测试。权重及记录位于 `artifacts/force_demo/`，所有数据、权重和结果都标为合成。该权重不能进入真机执行。
- RM75 适配器使用模拟SDK测试，并与实际安装的 Robotic_Arm 1.1.6 数据结构核对；未实例化真实设备连接。D435投影函数与已安装 RealSense SDK 比对通过；实际采集尚未验证。
- 手眼解析样例恢复与独立验证通过；合成样本仍输出 `validated=false`，不被当作实测标定。

## 视觉训练与现有限制

使用原有63张训练图、16张验证图重新训练 YOLOv8n 100轮，输出 `runs/detect_retrain/weights/best.pt`。完整训练日志在 `artifacts/yolo_training.log`，Ultralytics原始指标在 `runs/detect_retrain/results.csv`。这是现有小数据集的内部评价，不代表新D435场景的泛化性能。

原视觉批处理使用新权重及原Kinect占位内参检查79张图片，得到23张正常、51张警告、5张失败。可求解结果的平均重投影误差20.90331 px，中位数16.343851 px，最大135.814719 px。主要问题仍包含孔位缺失、对应不稳定和投影残差，报告为 `artifacts/batch_eval_control/latest_details.json`。其中包括训练图，不能将这79张作为独立测试集。

新控制入口会拒绝占位标定、非实时来源、错误时钟/帧身份及不满足质量条件的视觉消息。实际D435彩色流内参、序列号、手眼/工具外参和任务轴必须分别核验，不能把原Kinect近似参数用于新设备。

2026-10-27 视觉优化回归另见 [视觉优化记录](vision_optimization.md)。原报告保留；新结果、共同图片对比、覆盖下降及新增质量拒绝分别记录，不能将残差下降理解为真机精度验收通过。
