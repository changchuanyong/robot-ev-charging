# 低对比图片的暗孔回退路径

日期：2026-11-04（第二轮）。此次只在零输出图片上增加一条候选来源，不改阈值、不改预处理、不改在线定位链路、不重训模型、不修改标注。

## 问题定位

上一轮全库 326 张中有 194 张零输出，其中 168 张的主孔对数量为 0。逐张复跑后确认瓶颈不在配对门，而在主孔的可用测量：

| 观测 | 数值 |
| --- | ---: |
| 有孔径尺度轮廓被椭圆拟合以 `boundary_residual` 拒绝 | 168/168 张，中位 38 个/图（单图最多 82） |
| 通过 `promote_dark_apertures` 的孔径直径 | 多在 9–20 px（纹理小块） |
| 同一图真实 DC 孔直径（稳定暗区实测） | 约 45–65 px |
| 168 张中通过 review 主孔门的图片 | 0 |

原因是 `center_fit` 的残差门把低对比、带毛刺的边缘判为无效拟合，真实孔在 `MAX_KEEP=40` 的排序里沉底被截断，候选池只剩小噪声块；`observed_layout` 的主孔门（跨度 ≥0.25×ROI、孔径 ≥0.07×ROI、直径比 ≥0.70）据此正确地拒绝了它们。孔口对比度（暗孔中心对亮环）实测：有输出图片中位 33 灰阶，零输出图片中位 9 灰阶。

因此不能靠放宽配对门提升，只能补一条独立的孔径证据来源。

## 改动

`stable_dark_apertures`（多强度阈值稳定性 + 暗对比度 + 实测轮廓中心）原先只在主孔、PE、结构证据都已成立后才运行，用于补点。现在增加一条回退路径：

1. 主路径照旧，不改变任何既有行为；
2. 仅当主路径一个点都没输出时，把稳定暗孔候选并入候选池，再跑一次布局关联（`prefitted=False`）；
3. 回退路径成功才采用其结果，并且**不叠加** `complete_apertures`（补点逻辑定义在主路径的证据链上）；
4. 诊断字段新增 `fallback_used`、`primary_layout`、`stable_dark_candidate_count`。

因为回退只在零输出时触发，任何原本有输出的图片走不到新分支，坐标可逐点断言不变。

## 第三级：低对比剖面回退（同日追加）

第二轮回退后仍有 153 张零输出。检查增强链路发现 `preprocess_candidates` 先把 ROI 经过 `preprocess_roi`（含 CLAHE），再交给 `adaptive_canny_pipeline`，后者内部又执行一次 CLAHE + 双边：同一张图被局部增强两遍。低对比图上边缘像素占比 12–16%，`boundary_residual` 拒绝 42–67 个/图。

按 5 张可测已确认图、20 个可见参考点统计孔径候选 ≤10 px 命中：

| 预处理 | 孔径命中 | 边缘密度 |
| --- | ---: | ---: |
| 现状（CLAHE×2） | 4/20 | 12–16% |
| 去掉 min-max 拉伸 | 5/20 | 12–16% |
| 单次增强（去掉第二遍） | 5/20 | 10–12% |
| 加灰度世界白平衡 | 6/20 | 10–12% |
| 强局部对比（CLAHE 3.0 / 4×4） | 6 张已确认图仍 0 输出 | 更高 |

这批图的孔口只比周围深 2–10 灰阶，继续做局部对比只会把塑料纹理抬到同一量级。因此第三级用「不再增强」的剖面：灰度世界白平衡 → gamma → 光照归一（不做 0–255 拉伸）→ 双边，然后直接自适应 Canny。

实现：`enhance.low_contrast_gray`、`adaptive_canny_pipeline(prepared=True)`、`preprocess_candidates(profile="low_contrast")`；`suggest()` 只在主路径与暗孔回退都为空时调用，成功同样不叠加补点。

## 第四级：曝光剖面回退

暗色接头配亮桌面时，0–255 的大部分量程被背景占掉，孔口只剩几级量化。用尺度归一的环形匹配滤波测「真孔中心响应的分位」（100 = 全场最强）：

| 图片 | 原始 | 区域曝光拉伸后 |
| --- | --- | --- |
| `05204d4b` | 62 / 96 / 97 | 87 / 99 / 99 |
| `076e250f` | 86 / 99 / 99 | 95 / 100 / 100 |
| `08a39880` | 60 / 99 / 100 | 81 / 100 / 100 |
| `094b4824` | 54 / 62 / 68 / 88 | 84 / 87 / 88 / 94 |
| `06d863ab` | 75 / 83 / 92 / 98 / 100 | 86 / 90 / 94 / 97 / 100 |

曝光拉伸确实把弱孔从 54 分位抬到 84，但端到端只多出 5 张：把曝光剖面作为第三级时恢复 9 张，与低对比剖面数量相同、集合不同（交集 4 张），因此作为第四级追加。

实现：`enhance.exposure_gray` 在中心椭圆区域（0.48×宽、0.42×高）内按 2%–85% 分位拉伸，再双边；`preprocess_candidates(profile="exposure")`；`suggest()` 的回退顺序改为 `dark_aperture → low_contrast → exposure`，命中即停。

## 第五级：相对尺度主孔门

前四级之后仍有 135 张零输出。这些图的裁剪里背景占了大半，而主孔门的三条判据是相对裁剪尺寸的绝对值：跨度 ≥0.25×裁剪、孔径 ≥0.07×裁剪、直径比 ≥0.70。背景越大，真实主孔对越不可能同时满足。

第五级把这组绝对判据换成相对孔径的判据：直径比 ≥0.70，且跨度与平均孔径之比落在 2–6（孔不会重叠，主孔对相隔几个孔径）。严格门仍然先跑，只有它一个主孔对都给不出时才退回相对判据；并且只在前面四级全部零输出时触发。

23 张里 19 张只产出 3–4 个孔（部分布局），只有 2 张 `quality_ok`；已确认图没有一张走这条路径。**这条改动没有得到任何正确性验证**，只是覆盖率变化。

## 证据边界

- 图库现有 322 张活跃图（曾按错误判据排除 21 张，已恢复 18 张，保留 4 张排除），其中只有 13 张孔位已确认；当前 112 张零输出中仅 6 张已确认，覆盖数不能当识别率。
- 回退路径不会新增「合成」坐标：每个点都来自实测暗区轮廓的中心，但中心可能被阴影或反光带偏。
- 剩余 112 张的分诊见 `artifacts/vision_improvement_20261104/triage_v3/triage.html`：暗部贴底但孔口仍可测 14、整体欠曝 35、背景过曝 22、低动态范围 3、检测框失败 5、曝光正常但孔口响应弱 33。
- 分诊口径：只有孔径响应 <0.30 才判「孔口不可测」。第一版按「黑场截断 ≥5%」粗判会误报——接线面被压到 0–2 但孔口边缘仍比周围高几级，灰度图上轮廓可见。逐图证据：`artifacts/vision_improvement_20261104/triage/clipped/index.html`（红色为 ≤2 的像素）。
- 剩余 6 张已确认图里有 5 张只有 3–4 个可见参考孔，而布局门要求 ≥6 槽位 + CC2 方向证据，结构上不可达；放宽这条门等于用模板投影补出未观测的孔名，本项目不采用。
