## 如何复核

1. 打开入口页，依次进入会话 1（7 张）、会话 2（3 张）、会话 3（10 张）。画面中的青色点是助手目视预标注，记录为 `ai_visual`、`draft`，不是人工真值。
2. 先确认样件方向，再检查孔名及可见内孔口中心。样件存在旋转，不能固定按图像左右命名；正负极性与物理孔口截面也需核验。滚轮放大，点击修改当前孔中心，数字 1–9 选择孔，左右键切图。
3. 看不清就选择“不确定”或“遮挡”，不要根据理想布局补点。目标整体在画内，并不保证九孔都可见。
4. 填写复核人，逐图点击“确认本图已人工复核”，每个会话分别“导出 JSON”。建议保存为 `reviewed_black_session_1.json`、`reviewed_black_session_2.json`、`reviewed_black_session_3.json`，之后提供这三个文件路径。

页面只显示选中的 7 / 3 / 10 张，但导出仍分别保留完整会话的 **23 / 35 / 81 条**记录。未选图片仍为草稿，这是为了保留原会话、图像哈希及相机绑定；后续 `vision.diagnose` 只评价已复核图。原图、原始 Z16、相机参数和采集清单没有修改。

选图与预标注是开发流程，这 20 张仍属于已参加检测器训练的数据，没有被重新命名为独立测试集。像素评价容差应在重复标注检查后冻结，不根据效果调整。

## 候选去向图如何读

检测算法只增加观测记录，评分、筛选阈值、排序、合并和前 40 个候选的选择规则保持原样。`contour_diagnostics.candidate_trace` 的坐标为 ROI 像素，每个 `contour_index` 都有一个去向：

| 去向 | 含义 |
| --- | --- |
| `feature_rejected` | 退化轮廓，未形成候选特征 |
| `filtered` | 拟合、暗孔对比、面积或边界等检查未通过 |
| `merged` | 合并到另一候选；记录代表轮廓编号及孔口信息是否转移 |
| `kept` | 去重后保留在前 40 个内 |
| `capped` | 去重后排序超过 40，未进入布局关联 |

逐孔图以 AI 草稿坐标为检索位置，显示各阶段最近的轮廓及像素距离；JSON 保留合并去向。**距离近不证明它是真实孔口，也不证明筛除原因就是该孔丢失的原因。** 这些图用于定位待检查的轮廓，人工复核后再判定候选召回、错名和漏孔。未标坐标的遮挡/不确定孔不进行邻近检索。
